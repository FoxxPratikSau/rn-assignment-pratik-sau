Used Expo to build this app. 
## To run the app
```
npm install
npx expo start --clear
```
You can run the app on your phone or simulator. You can use the Expo Go app to scan the QR code from your terminal.

## State Management
I used Zustand for state management. I also used React Query to fetch data from the API.

## Styles
There is two modals one for Profile and one for Job Detail.
